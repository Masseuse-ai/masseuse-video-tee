# Contributing

This repository is published so that anyone can read what the program does
and verify that a download is the program (`VERIFY.md`). It does not take
contributions: pull requests, issues and discussions are closed to the
public, and every change is made by the project's release identity through
a pull request that the repository's checks accept. Forks for reading and
building are of course welcome.

To report a vulnerability, use the security advisory form linked from
`SECURITY.md`; please do not open a public pull request for it.
